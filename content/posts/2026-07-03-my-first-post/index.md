今天把个人网站搭起来了，主要用到：

- **Hugo** —— 静态网站生成器，构建一次全站只要几十毫秒
- **PaperMod** —— 一个干净的极简主题
- **GitHub Pages** —— 免费托管，`git push` 就自动上线

## 写作流程

从今以后，写新文章就三步：

1. 打开编辑器写好 Markdown
2. `hugo server` 本地预览一下
3. `git add . && git commit -m "..." && git push`

大概 1 分钟后线上就更新了。
