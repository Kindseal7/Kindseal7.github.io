## 想做什么

我想生成一些有立体感的符号图形。最初的要求很简单：用一句指令描述想要的感觉，然后得到一个看起来有深度、会运动、可以交互的结果。这个项目使用 Codex 协作完成。

最终交付的页面不是一个需要后端或模型实时推理的生成服务，而是一个零依赖的静态展示页。图形由浏览器中的 JavaScript 程序化构造，符号节点、连线、旋转、透视和颜色都在 Canvas 上实时绘制。

## 页面包含的功能

当前页面提供 12 种预设对象，包括硬币、立方体、球体、钻石、圆环、金字塔、双螺旋、波形、星形、晶格和胶囊等。每种对象由不同的节点构造函数生成，再根据节点距离建立连线。

用户可以：

- 切换图形预设；
- 调整旋转速度和透视；
- 调整符号密度和连线强度；
- 切换青色、紫色、琥珀色和黄绿色主题；
- 暂停或继续动画；
- 随机切换图形；
- 拖拽旋转视角；
- 用滚轮缩放；
- 进入全屏；
- 在移动端使用同一页面布局。

## 实现过程

程序首先在三维坐标中生成节点。不同的形状使用不同的构造方式：例如圆柱体按多个圆环和端面采样，球体使用类似 Fibonacci 球面分布的点，金字塔和钻石通过顶点、边界和面内插值生成，双螺旋和波形则直接按参数方程生成。

渲染时先对节点进行偏航和俯仰旋转，再根据深度做透视投影，把三维坐标映射到 Canvas。节点按深度排序，连线使用透明度表达远近，符号大小、透明度和阴影也随深度变化。浏览器通过 `requestAnimationFrame` 驱动动画，并显示当前帧率。

交互部分使用 Pointer Events 处理鼠标和触摸拖拽，用 `wheel` 处理缩放，并监听空格和 `F` 键处理暂停和全屏。改变节点密度或连线强度时会重新构造网络，而不是只改变 CSS 外观。

## 交付物

- `index.html`：展示区域、控制面板和交互入口；
- `app.js`：形状构造、三维投影、Canvas 渲染和交互；
- `styles.css`：桌面端和移动端布局、主题与控件样式；
- `README.md`：本地运行和 GitHub Pages 部署说明；
- GitHub Actions Pages 发布配置；
- 公开源码仓库：[Kindseal7/symbol-field](https://github.com/Kindseal7/symbol-field)。

## 结果和边界

这个项目已经形成一个可以直接打开和部署的静态视觉实验页，也实现了预设图形、参数控制和基本三维交互。这里的“一句指令”是项目的设计起点，并不是页面运行时会理解自然语言并动态生成任意新图形；当前版本使用的是代码中定义的预设形状和参数。

它也不是物理意义上的 3D 引擎，节点和连线是 Canvas 2D 绘制出来的三维投影效果，没有使用 Three.js、模型推理或后端服务。视觉效果依赖采样密度、投影参数和颜色主题，暂时没有记录系统化的性能测试或跨浏览器兼容性测试。

## 如何运行

在项目目录执行：

```bash
python -m http.server 4173
```

然后打开 `http://localhost:4173`。项目不需要 API Key、数据库或服务器端接口，推送到 `main` 后可以通过仓库中已有的 GitHub Actions 配置发布为静态页面。
