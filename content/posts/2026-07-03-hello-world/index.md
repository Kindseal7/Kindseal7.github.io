## 一、标题层级

用 `##` `###` `####` 表示二级到四级标题，一级标题（`#`）留给文章 title 自己。

## 二、插入图片

图片直接放在**和 `index.md` 同一个文件夹**里，然后：

```markdown
![图片说明](图片文件名.jpg)
```

如果需要控制宽度：

```html
<img src="图片文件名.jpg" width="400" alt="说明">
```

## 三、代码块

用三个反引号包起来，指定语言可以获得语法高亮：

```python
def hello(name):
    print(f"你好，{name}")

hello("世界")
```
