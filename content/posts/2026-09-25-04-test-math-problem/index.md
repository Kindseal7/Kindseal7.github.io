## 先说明结论边界

这个项目不是孪生素数猜想的证明，也没有把已知公开纪录 246 推进到 200 以下。它记录的是一次围绕有界素数间隔的独立数值实验：在 Maynard–Tao 筛法的一个受限权重族和一组程序化构造的容许元组上，得到一个数值上稳健的 278。

“278”应理解为“理想化判据加数值优化”意义下的结果。现有文章明确指出，没有对完整定理中的所有 `o(1)` 误差项和 `ε` 余量做形式化验证，数值误差约为 `±0.3%`。因此它是可复现的研究记录和路线分析，不是新的定理或新的公开纪录。

项目使用 Claude Code 和 GLM-5.3 协作推进。当前目录中的 `paper.html` 保存了较完整的研究报告，脚本和 JSON 文件保存了计算过程与中间结果。

## 问题和目标

工作从“尝试推进孪生素数猜想”的目标出发，后来被具体化为两个数值目标：

- 目标一：尝试把间隔推进到小于 200；
- 目标二：尝试把间隔推进到不超过 100。

筛法侧的核心量是 `M_k`。在理想化判据下，需要找到 `M_k > 4`，同时还需要一个直径较小的容许 `k`-元组。项目没有只追一个最终数字，而是分别观察了需求侧的 `M_k`、元组直径 `d(k)`，以及供应侧素数在等差数列中的经验分布。

## 主要实现步骤

### 1. 从乘积权重开始

最初使用乘积权重

`F(t_1, ..., t_k) = ∏ f(t_i) · 1_{Σt_i ≤ 1}`。

在这个权重族中，多维积分可以精确约化为一维卷积。程序使用中点网格表示函数，用卷积幂计算 `I_k` 和 `J_k`，再得到 `M_k`。`maynard_sieve.py` 中包含函数族、卷积层缓存、数值积分和 Nelder–Mead 优化。

### 2. 构造容许元组

`tuples.py` 从 `{0}` 开始逐步加入仍保持容许性的最小整数，得到贪心直径 `d(k)`。它还检查了代码中记录的 Engelsma 105-元组是否容许。已有小规模结果被用来做校准，例如 `d(50)=246`，`d(56)=278`，`d(105)=608`。这里的贪心结果是直径上界，不自动等于所有情形下的最优值。

### 3. 扩展权重和随机搜索

`enrich.py` 在乘积权重之外加入 `G(Σt_i)`，把问题仍然写成卷积和一维积分，并交替优化 `f` 与 `G`。同一阶段还尝试了双侧随机贪心构造元组，使用多次重启比较直径是否能优于单侧贪心。

### 4. 供应侧经验测量

`distribution.py` 取 `x=10^8` 范围内的素数，对不同规模和类型的模数计算归一化的卡方统计量，比较全体模数、素数模数和光滑模数的经验分布。这个实验用于观察 `θ≈0.53` 和 `θ≈0.62` 附近是否出现明显的经验障碍，但代码注释和报告都强调：经验测量不是分布定理的证明。

## 数值校准和修复

项目没有只运行优化程序然后接受输出，而是先设置了可解析校准点：当 `f≡1` 时，理论值为 `M_k=2k/(k+1)`。研究过程中记录并修复了几类问题：

- 早期 FFT 卷积在高维、动态范围很大的情况下产生严重舍入误差，后来改为直接卷积和逐层重标定；
- 交替优化中曾出现目标值符号处理错误，导致改进结果被丢弃；
- 自由形状节点均匀分布不适合质量集中在 `t≈0` 的区域，后来把节点向该区域集中；
- `k=54` 的临界结果在更高分辨率复验后跌回 4 以下，因此原先更激进的 270 声明被撤回。

`debug.py` 用精确二项式卷积路径复现 `f≡1` 的计算，`confirm.py` 对 `k=23、56、105` 做重新优化和高分辨率迁移，帮助区分公式、网格和实现误差。

## 最终结果

报告中采用的稳健交叉点是 `k=56`：

- `M_56` 在 `N=8192` 时约为 `4.041`；
- 迁移到 `N=16384` 后约为 `4.032`；
- 贪心构造得到 `d(56)=278`。

因此，在报告采用的理想化判据下，项目记录为间隔上界 278。更接近阈值的 272 被列为高置信但余量较小；270 因高分辨率复验不足 4 而撤回。对小于 200 和不超过 100 的目标，报告把主要缺口分别定位到需求侧的 `M_43` / `M_23` 不足 4，以及供应侧需要超过 Bombieri–Vinogradov 的分布水平。

## 交付物

- `maynard_sieve.py`：乘积权重、卷积计算、优化和基础校准；
- `tuples.py`：容许元组检查、贪心构造和直径表；
- `enrich.py`：加入 `G(Σt)` 的扩展权重与双侧随机贪心；
- `push.py`：自由形状权重的交替优化和临界值复验；
- `distribution.py`：素数分布经验测量；
- `debug.py`、`confirm.py`：数值调试和最终确认；
- `mk_results.json`、`mk_results2.json`、`mk_results3.json`：不同阶段的数值结果；
- `Mk_sweep.npy`：扫描结果数据；
- `paper.html`：包含推导、校准、问题定位、结果和复现说明的研究报告。

## 复现和限制

项目依赖 Python 3.11+、NumPy，并需要在包含这些脚本的目录运行。数值优化涉及随机重启、离散网格和有限精度，重新运行不一定逐位得到相同结果。报告给出的误差范围来自校准实验，不等于完整数学证明中的误差控制。

这次工作的实际成果，是把一条数值路线实现出来，记录了从卷积计算、元组构造、供应侧测量到错误修复的过程，并把当前方法距离 200 和 100 的缺口写清楚。它没有解决孪生素数猜想，也没有宣称取得新的数学纪录。
